# KAngel for ChatGPT Work

KAngel is a fan-made pixel-art pet for ChatGPT Work. It reimagines KAngel from *NEEDY GIRL OVERDOSE* as a retro RPG-style desktop companion. [Official game site](https://whysoserious.jp/needy/)

## Download

[Download the KAngel pet ZIP](./kangel-pets-package.zip?raw=true). It includes the original exported v2 sprite sheet, a looping idle preview, and English setup instructions. The sprite sheet contains nine animation states and sixteen gaze directions.

## Install in ChatGPT Work

1. Attach the ZIP to a ChatGPT Work conversation with Pets available.
2. Send this request.

   > Use Pets to create a custom pet named KAngel from `kangel-spritesheet.png` in this ZIP, then select it as my active pet.

3. If the chat cannot open the ZIP, extract it and attach `kangel-spritesheet.png` directly with the same request.
