# NEEDY GIRL OVERDOSE Heroine Pet

A fan-made pixel-art pet for ChatGPT Work based on the heroine of *NEEDY GIRL OVERDOSE*. [Official game site](https://whysoserious.jp/needy/)

## Download and install

1. Download the [heroine pet ZIP](./needy-girl-overdose-heroine-pet.zip?raw=true).
2. Attach it to a ChatGPT Work conversation with Pets available and send this request.

   > Use Pets to create a custom pet named NEEDY GIRL OVERDOSE Heroine from `heroine-spritesheet.png` in this ZIP, then select it as my active pet.

3. If the chat cannot open the ZIP, extract it and attach `heroine-spritesheet.png` directly with the same request.
